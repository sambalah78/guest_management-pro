# EventLah Guest Management

Production-oriented event and guest management application built with Python and Reflex.

## Stack

- Reflex 0.9.x
- PostgreSQL (SQLite for local development)
- SQLAlchemy
- Google OAuth
- Google Drive (`drive.file`) for application files
- Gmail SMTP for email delivery
- Durable email worker
